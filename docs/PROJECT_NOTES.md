# Project Notes

## Objective
Build a lightweight Linux C++ network chaos emulator for controlled UDP experiments.

## Core concepts
- POSIX socket programming
- UDP datagrams
- Packet dropping
- Artificial latency
- Jitter
- Bandwidth delay
- Runtime statistics
- Signal handling
- Make-based compilation

## Development sequence
1. Environment setup
2. UDP sender/receiver
3. Chaos engine
4. Runtime configuration
5. Statistics
6. Jitter
7. Bandwidth control
8. Testing and documentation
9. GitHub submission
